## Installation

For the installation instructions, read the [installation page](/documentation/installation/packages/dremel.md).

Dremel is a php implementation of the [Google Dremel](https://static.googleusercontent.com/media/research.google.com/pl//pubs/archive/36632.pdf) paper.
This library flattens nested data structures into a columnar format, and later hydrates them again. Queries on a columnar format are more efficient.

This library gives the PHP Parquet implementation its support for nested structures.
