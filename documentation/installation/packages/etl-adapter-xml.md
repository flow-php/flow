## Composer

```bash
composer require flow-php/etl-adapter-xml:~--FLOW_PHP_VERSION--
```

## Required PHP Extensions

- `ext-dom`
- `ext-xml`
- `ext-xmlreader`
- `ext-xmlwriter`

These extensions are typically bundled with PHP.
