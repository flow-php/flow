## Composer

```bash
composer require flow-php/etl-adapter-elasticsearch:~--FLOW_PHP_VERSION--
```

## Core Dependencies

- [elasticsearch/elasticsearch](https://packagist.org/packages/elasticsearch/elasticsearch)

## Required PHP Extensions

- `ext-hash`
- `ext-json`
