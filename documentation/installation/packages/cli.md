# Flow PHP CLI

[DOC_LINK:/documentation/components/cli/docs.md]

## Composer

```bash
composer require flow-php/cli:~--FLOW_PHP_VERSION--
```

## Global Installation

```bash
composer global require flow-php/cli:~--FLOW_PHP_VERSION--
```

## Docker

Flow CLI is also available as a Docker image. See [Docker installation](/documentation/installation/docker.md) for details.
