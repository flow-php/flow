# Extension: pg_query

A compiled PHP extension for PostgreSQL query parsing using [libpg_query](https://github.com/pganalyze/libpg_query),
providing SQL parsing into JSON AST, query fingerprinting, normalization, PL/pgSQL parsing, statement splitting, and tokenization.
