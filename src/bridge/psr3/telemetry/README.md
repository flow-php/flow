# PSR-3 Telemetry Bridge

Bridge connecting Flow PHP Telemetry library with PSR-3 logger interface, allowing log records to be emitted as telemetry log signals.

> [!IMPORTANT]  
> This repository is a subtree split from our monorepo. If you'd like to contribute, please visit our main monorepo [flow-php/flow](https://github.com/flow-php/flow).
