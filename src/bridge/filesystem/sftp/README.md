# Filesystem SFTP Bridge

This package provides a bridge between the [Filesystem](https://github.com/flow-php/filesystem) and [phpseclib](https://github.com/phpseclib/phpseclib), so that `sftp://` paths can be used anywhere Flow accepts a path.

> [!IMPORTANT]  
> This repository is a subtree split from our monorepo. If you'd like to contribute, please visit our main monorepo [flow-php/flow](https://github.com/flow-php/flow).
