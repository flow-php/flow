# Telemetry OTLP Bridge

OTLP (OpenTelemetry Protocol) exporter bridge for Flow PHP Telemetry library, enabling export of traces, metrics,
and logs to any OTLP-compatible backend such as SigNoz, Jaeger, Grafana, Sentry, Datadog, Honeycomb, and New Relic.
