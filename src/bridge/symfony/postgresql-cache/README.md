# Symfony PostgreSQL Cache Bridge

Symfony Cache adapter backed by Flow PHP's native PostgreSQL library — replaces `symfony/doctrine-dbal-adapter` without requiring Doctrine DBAL.

> [!IMPORTANT]  
> This repository is a subtree split from our monorepo. If you'd like to contribute, please visit our main monorepo [flow-php/flow](https://github.com/flow-php/flow).
