# Symfony PostgreSQL Session Bridge

Symfony session handler backed by Flow PHP's native PostgreSQL library — replaces `PdoSessionHandler` without requiring PDO or Doctrine DBAL.

> [!IMPORTANT]  
> This repository is a subtree split from our monorepo. If you'd like to contribute, please visit our main monorepo [flow-php/flow](https://github.com/flow-php/flow).
