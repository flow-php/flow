# code_editor_controller.js

CodeMirror-based PHP editor with syntax highlighting and error display.

## Public Methods

### `getCode(): string`
Returns current editor content.

### `setCode(code: string): void`
Replaces editor content with provided code.

### `setValue(code: string): void`
Alias for `setCode()`.

### `highlightError(errorInfo: { line, type, message, column }): void`
Highlights error line in editor and scrolls to it.

**Parameters:**
- `errorInfo.line` - Line number (1-indexed)
- `errorInfo.type` - Error type (e.g., "ParseError", "TypeError")
- `errorInfo.message` - Error message
- `errorInfo.column` - Column number (optional)

### `clearErrors(): void`
Removes all error highlights from editor.

### `isLoaded(): boolean`
Returns true if editor is initialized and ready.

### `onLoad(): Promise<void>`
Returns promise that resolves when editor is ready.

## Events Dispatched

### `code-editor:code-changed`
**Trigger:** User edits code in editor
**Payload:** None
**Bubbles:** Yes

## Features

- PHP syntax highlighting (CodeMirror PHP mode)
- Flow PHP autocompletion (`assets/codemirror/flow_completion.js`):
  - DSL functions and classes, with an automatic `use function` / `use` import when the name is free
  - `class`, constants, enum cases and static methods after `Class::`
  - named arguments not used yet at the start of an argument, `$variables` with their resolved type
- Hover tooltips (`assets/codemirror/flow_tooltips.js`): signature and docblock of functions and methods, class names,
  variable types
- Parameter hints: the signature of the enclosing call above the cursor, current parameter highlighted
- Cmd/Ctrl + click opens the documentation: DSL page for functions, API page for methods, constants and classes;
  signatures in tooltips are highlighted with Prism, like the code samples on the site
- Code samples on the site link through the same analysis (`assets/prismjs/plugins/autolinker/autolinker.js`)
- Shared PHP analysis (tokens, imports, type resolution, enclosing call): `assets/codemirror/php_analysis.js`
  - methods after `->` / `?->`, typed from the expression on the left: DSL calls, method chains, `new`, assigned
    variables and typed parameters
  - data: `assets/codemirror/completions/flow-api.js`, generated by `bin/console app:generate:code-completion` from
    `resources/dsl.json` and `resources/api.json` (`just docs`)
- Tab accepts the selected suggestion, otherwise indents
- Error line highlighting with hover messages
- Syncs with hidden textarea for form submission
